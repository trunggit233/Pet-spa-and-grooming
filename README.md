# 🐾 Pet Spa & Grooming — Landing Page

> Landing page chuyên nghiệp cho dịch vụ Spa & Grooming thú cưng.

## Tech Stack
- **HTML5** — Semantic markup
- **CSS3** — Custom Properties, Grid, Flexbox, Container Queries
- **Vanilla JS** — ES Modules, no framework

## Getting Started

Mở `index.html` trong trình duyệt hoặc sử dụng Live Server.

```bash
# VS Code Live Server
# Hoặc dùng bất kỳ static file server nào
npx serve .
```
